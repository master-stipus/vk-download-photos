# vk-download-photos

## Какой в этом смысл

Мне потребовалось скачать приличное количество фотографий из беседы в VK. Изображения лежали на галимых CDN-серверах и были доступны по ссылкам вида [https://*.vkuserphoto.ru/...](https://www.google.com/search?q=купить+опарышей+для+рыбалки). Но в процессе загрузки я столкнулся с непредвиденным конфузом: для одного и того же изображения сервера возвращали различные значения заголовка `Last-Modified`. При использовании метода `HEAD` я получал либо реальное время модификации, либо время отправки запроса. С методом `GET` добавлялся третий вариант — нулевое Unix-время.

## Мое решение

Скачиваем изображение методом `GET`, получаем его метаданные методом `HEAD` и извлекаем из них значение `Last-Modified`. Устанавливаем его в качестве метки времени для скачанного изображения. Решение неидеальное, периодически (но достаточно редко) `HEAD` получает дату отправки запроса, но с нулевым Unix-временем я ни разу не столкнулся на выборке из 100+ фотографий. В случае некорректной даты мне помогло повторное выполнение описанного алгоритма.

Для частичной автоматизации я написал скрипт `blowjob.sh`. Создайте в одной директории с ним текстовый файл `links.txt`, на каждой строке разместите ссылку на изображение (**в конце файла должна быть пустая строка!**). Запустите скрипт, затем посмотрите на вывод: в имени каждого скачанного файла будет присутствовать временная метка. Проверьте ее на корректность. Для ссылок с проблемными метками запустите скрипт еще раз.
