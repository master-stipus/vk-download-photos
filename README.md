# vk-download-photos

## Какой в этом смысл

Мне потребовалось скачать приличное количество фотографий из беседы в VK. Изображение лежали на галимых CDN-серверах и были доступны по ссылкам вида [https://*.vkuserphoto.ru/...](https://www.google.com/search?q=купить+опарышей+для+рыбалки). Но в процессе загрузки я столкнулся с непредвиденным конфузом: для одного и того же изображения сервера возвращали различные значения заголовка `Last-Modified`. Метод `HEAD` возвращает реальную дату модификации или дату отправки запроса. Метод `GET` также может вернуть нулевое Unix-время.

## Решение

Скачиваем изображение с помощью метода `GET`, затем получаем его метаданные с помощью `HEAD` и извлекаем из них значение `Last-Modified`. Устанавливаем его в качестве метки времени для скачанного изображения. Решение неидеальное, периодически (но достаточно редко) `HEAD` получает дату отправки запроса, но с нулевым Unix-временем я не столкнулся на выборке из 100+ фотографий. В случае некорректной даты помогло повторное выполнение описанного алгоритма.

Для частичной автоматизации я написал скрипт `blowjob.sh`. Создайте в одной директории с ним текстовый файл `links.txt`, на каждой строке разместите ссылку на изображение (**в конце файла должна быть пустая строка!**). Запустите скрипт, затем посмотрите на вывод: в имени каждого скачанного файла будет присутствовать временная метка. Проверьте ее на корректность. Для ссылок с проблемными метками запустите скрипт еще раз.
